# Changelog

## 0.1.0 — 2026-11-04

- Added Pydantic data/result/report contracts and validated UTF-8 JSONL loading.
- Added nine deterministic metrics with explicit skipped/error statuses.
- Added a sequential extensible evaluator and descriptive score aggregates.
- Added opt-in judge contracts, four judge metrics, bounded OpenAI-compatible
  transport, versioned rubrics, and exact context-evidence validation.
- Added JSON, CSV, and Markdown exporters with configuration and coverage.
- Added paired direction-aware regression checks and multi-dataset manifests.
- Added CLI commands, synthetic examples, offline tests, contributor docs,
  privacy/security notes, and Python 3.11–3.13 CI configuration.

Initial alpha. No claims of public benchmark performance, provider certification,
research validation, or production adoption accompany this release.
